# 상품 등록 운영 기준

카페24에서 하던 상품등록 경험을 유지하되, Medusa Admin을 상품 운영 화면으로 사용한다.

## 신규 1개
1. Product 생성
2. 제조사 모델/품번을 Variant SKU에 입력
3. KRW 가격 입력
4. 브랜드/규격/바코드 확인
5. metadata에 WORKNIC section과 POS code 기록
6. 공식 상품 이미지 업로드
7. Draft에서 상세 검수
8. Published 전환

## 대량 등록
POS 원장을 바로 공개하지 않는다. 변환 레이어에서 `POS 상품코드 + 브랜드 + 제조사 모델 + 규격 + 바코드`를 먼저 정규화한다. A 검증 상품부터 Medusa import 형식으로 변환한다.

## 공개 기준
- REFILL: 반복 소모 + 규격 깊이
- TOOLS: 자주 필요한 기본 도구
- SELECT: 판매량보다 관계/제품 피드백/선택 이유가 기록된 제품
- PROJECT: 상품을 복제하지 않고 기존 SKU를 작업 관계로 연결

## 금지
- 현재고 필드 없이 `오늘 픽업 가능`, `2개 남음` 등을 추정하지 않는다.
- 상품명 fuzzy match만으로 POS와 온라인 상품을 합치지 않는다.
- 경쟁사 이미지를 사용하지 않는다.
- SELECT를 프리미엄/고가 상품 순위로 만들지 않는다.
